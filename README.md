# Sistema de Controle de Produtos em Python

Projeto desenvolvido durante meus estudos de Python.

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Busca de produtos
- Atualização de estoque
- Edição de produtos
- Exclusão de produtos
- Cálculo do valor total do estoque
- Persistência de dados utilizando JSON
- Validação de dados
- Tratamento de erros

## Tecnologias

- Python
- JSON

## Objetivo

O objetivo deste projeto é praticar fundamentos de programação e evoluir gradualmente o sistema conforme avanço nos estudos de Python.
